# Phase 06 Evidence Directory

Phase 06 is not complete until a real-model validation run has been inspected, the protocol has been frozen, and the single authorized locked-test baseline has been preserved and recomputed.

Current repository state intentionally contains **no fabricated real benchmark evidence**. The committed `validation-review.template.json` is only a template; its false/default fields must not be changed to passing values without manually inspecting every real validation prediction.

Expected evidence after real execution:

- `validation-run.json` — deterministic export from the real validation run in PostgreSQL.
- `validation-review.json` — human review covering every validation prediction.
- `protocol-freeze.json` — generated by `scripts/freeze_phase6_protocol.py --apply` only after validation evidence and review pass.
- `test-run.json` — deterministic export from the single authorized real locked-test baseline.
- `runtime-environment.txt` or equivalent immutable runtime capture from the GPU host.
- W&B run/artifact references embedded in the run export when W&B is configured.

The export checksum covers predictions, metrics, cost records, run/config identity, tracking references, and the exact held-out incident IDs. `scripts/freeze_phase6_protocol.py` refuses to authorize the locked test if validation evidence is incomplete, duplicated, checksum-invalid, scientifically inconsistent with the protocol, or not manually reviewed.
